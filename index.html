Local Storage & Security Notice

Security Architecture:

  • Zero Server Middleman: NexusAI has no database or telemetry server. API requests connect directly from your browser to your selected provider.
  • AES-256 Web Crypto Encryption: API Keys are encrypted locally using PBKDF2 + AES-GCM before writing to `localStorage`.
  • Browser Cache Backup: Clearing browser data removes local history. Use the Backup button in the sidebar anytime to export an encrypted JSON backup.
